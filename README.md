# 🌕 South Pole Landing Site Planner (`astromoon-lunar-reach`)

An interactive web application designed to analyze and evaluate optimal lunar south pole landing sites for future space missions.

## 🚀 Overview

The **South Pole Landing Site Planner** helps users visualize, assess, and plan lunar landing missions near the Moon's South Pole—a region of key interest for science and exploration due to permanently shadowed regions (PSRs) and potential water ice deposits.

## ✨ Key Features

- **Interactive Lunar Mapping**: Visualize landing sites and surface topography near the lunar South Pole.
- **Site Evaluation Criteria**: Assess landing zones based on illumination, slope, and resource accessibility.
- **Mission Planning Tools**: Tools for analyzing potential trajectories and landing hazards.
- **Responsive Web Interface**: Optimized for easy navigation across desktop and web browsers.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Deployment**: GitHub Pages
